# 主流 embedding 对比结论

本轮新增6个基线，完成324次训练、162次验证集选模后的测试评测，并与原有 OmniJev / Qwen3.5 base / FLAIR 在同一批28,263张图像和同一检索协议上比较。三个数据域分别训练，训练量为25/50/100%，每条件3个随机种子、2个学习率、1,000步。

## 主结果

完整训练量下，属性宏平均 mAP（%，三种子均值±样本标准差）：

| 方法 | Fashion | CUB | DTD |
|---|---:|---:|---:|
| OmniJev raw | **82.10 ± 0.21** | 44.36 ± 0.10 | 49.37 ± 0.25 |
| Qwen3.5 base raw | 71.89 ± 1.32 | 41.02 ± 0.06 | 49.94 ± 0.63 |
| FLAIR | 74.50 ± 0.39 | 43.41 ± 0.03 | 50.88 ± 0.35 |
| CLIP B/32 | 69.22 ± 0.15 | 42.48 ± 0.09 | 45.95 ± 0.50 |
| SigLIP2 B/16 | 71.29 ± 0.07 | 43.84 ± 0.06 | 62.94 ± 0.42 |
| DINOv2 Small | 67.44 ± 0.17 | 43.80 ± 0.09 | 53.83 ± 0.22 |
| Qwen3-VL API | 68.63 ± 0.14 | 44.35 ± 0.05 | 65.42 ± 0.14 |
| Qwen3-VL API + 属性 instruct | 79.90 ± 0.56 | **47.38 ± 0.03** | 65.43 ± 0.17 |
| Tongyi Vision Plus 2026-03-06 | 72.12 ± 0.10 | 44.12 ± 0.23 | **65.95 ± 0.09** |

这些行使用同一种共享 LN+Linear256 head 和训练步数，但输入维度、head参数量、backbone、预训练、分辨率和服务计算量不同，不是等参数或等算力对照。API 不公开精确权重与参数量。CLIP/SigLIP2/DINOv2/通用API的多slot实际上是同一向量复制，不能据此认为它们支持属性选择。

**不能再讲“OmniJev embedding 全面优于主流模型”的故事。** OmniJev raw 在 Fashion 属性宏平均上仍领先；CUB 的最强对照是 Qwen 属性 instruct；DTD 上 SigLIP2 与两个专用 API 都明显优于 OmniJev。在冻结、完全不训练投影的原生向量对照中，OmniJev 也不是最强，完整表见 `RESULTS_V4.md`。

这里“最好”指本轮 raw-head 表的数值最大值；v3 包含额外 residual、gate 与联合损失结构，不与这张控制表混排。三个种子的标准差不是对总体泛化的置信区间，不作统计显著性结论。

## 最直接的属性条件证据

同一 Qwen API、相同原生2560维，改变是否传固定属性 instruct：

| 数据域 | 不训练时属性 mAP 变化（百分点） | 适配后变化（配对种子均值±SD，百分点） |
|---|---:|---:|
| Fashion | +3.23 | **+11.28 ± 0.42** |
| CUB | +1.44 | **+3.03 ± 0.05** |
| DTD | −1.44 | +0.01 ± 0.23 |

Fashion 的颜色、类别、受众字段分别从46.48/72.84/86.56提升到64.51/82.91/92.30。CUB 的颜色、喙形、翼形从55.06/42.93/35.07提升到58.69/47.72/35.72。翼形改善很小；不能只凭宏平均声称每种证据都学好了。

这个结果支持“把固定属性方向提前编码进可复用向量，对多属性检索有价值”。它同时削弱“这一能力只能从决策模型迁移”的主张：现成专用 embedding API 加 instruct 就能实现，并在 CUB 超过本地 OmniJev。它也不是统一embedding存储预算的对照：三属性条件版需要三次方向编码及三个向量，通用版只需一次编码和一个向量。

属性平均更好不意味着任意组合检索都更好。Fashion 中 Qwen instruct 的全局联合 mAP 为54.34±0.76，通用版55.21±0.03；Tongyi 达67.87±0.25。属性方向的独立可检索性与全局多条件联合度量是两个目标，不能互相替代。

## 数据量和 output projection

Fashion 在固定1,000步预算下各模型变化很小；CUB 多数模型缓慢提升。DTD 增大训练量的收益明显，例如 SigLIP2 从55.50到59.27再到62.94，Tongyi 从58.91到63.25再到65.95。新模型162个被选checkpoint中114个在第1,000步最好，不能称已充分收敛。

本轮不改变 v3 的输出投影实验。**拼接后不必强制加 output projection**：它是可学习的压缩/联合度量步骤，要由验证集和存储预算决定。v3 等联合训练下，压缩相对拼接的全局 mAP 变化仍为 Fashion +0.95、CUB −0.02、DTD −0.98个百分点。需要单属性检索时，独立 slots 仍须保留；一个全局压缩向量不能自动替代它们。

## 可复现与边界

- 全部324个导出head重载后，验证mAP最大误差为0；324份最终optimizer/RNG恢复状态全部保留。
- 通用CLIP特征和三slot Qwen特征均实测连续4步与2+2断点续跑完全一致。
- 18组“数据域×backbone”各取两张训练图重新编码，head输出最大绝对差2.98e-8；这证明本次缓存与推理路径一致，不能保证未来API别名不变化。
- 16,264个成功主提取请求，额外重试0。实际返回token约402万/1,052万/1,139万；不包括预检和新图核验的小量调用，也不等于服务商账单。
- 所有模型共享已公开的 v3 测试划分，本轮未用测试调参，但这不是新收集的未见测试集。公开数据可能已进入大模型预训练，无法排除。
- DTD 是split1检索，CUB使用可信正属性集合并排除缺失值；不等价于官方分类榜或标准MMEB。纯文本embedding需要另设caption管线，未在本轮直接比较。
- 不发布原始图片、上游backbone权重、API密钥或服务端权重。Qwen服务别名不可固定，特征缓存完整保留在本地；未来独立重算不保证逐位一致。

正式项目当前能报告的是：**固定方向的可复用属性记忆在多属性任务有效，但不是OmniJev独有优势；decision-head门控并未证明优于直接属性hidden投影；主流embedding模型在纹理任务上更强。** 要建立新的决策敏感性迁移主张，还需要未见属性/组合和关键证据反事实评测，以及与通用特征独立属性head的额外公平对照。本轮没有完成这些新实验，不将它们写成已有发现或新颖性证明。
